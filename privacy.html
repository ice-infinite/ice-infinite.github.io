隐私与内测说明

更新日期：2026-10-19 · 适用于本站当前提供的 Android 内测版本

你可以先了解这些信息，再决定是否下载。不注册，也能使用安药箱的本机药品管理功能。

这是公开内测，不是正式发行版。

当前安装包采用测试签名，功能和兼容性仍需测试。建议先备份重要数据。App用于记录家庭药品库存和标签有效期，不提供诊断、剂量或用药建议，也不保证提醒在所有手机上都能送达。

1. 不登录时，数据留在哪里？

基础药品记录、药箱、位置和提醒计划保存在手机本机。可以不注册账号、不购买硬件，离线使用这些基础功能。卸载或清除应用数据可能丢失本机记录，请先使用 App 的备份功能。选择文件导出后，文件的保存位置、接收方和保护方式由你自行确认。

2. 当前内测默认开启基础使用统计

为了了解有多少安装在使用 App，本次内测构建默认开启基础使用统计。它不是使用基础功能的条件，关闭后仍可以管理药品。之前已经明确关闭的选择，不会因本轮覆盖更新而重新开启。

  • 提交内容：应用编号、随机安装标识、实际使用日期、App版本和系统平台。
  • 统计不收集药品名称、库存、照片、语音、手机号、邮箱、定位、IMEI和MAC地址，不关联账号或药品正文。
  • 随机安装标识不是硬件编号；服务器用于去重的安装标识摘要仍按隐私数据管理，并不因此等同于完全匿名数据。
  • 每日活跃明细保留90天；累计激活去重摘要继续保留。统计代表安装活跃情况，不等于精准使用人数。

关闭位置：App「我的 → 隐私与权限 → 使用情况统计」，关闭「允许基础使用统计」。关闭后停止提交并清理待上传记录；已提交的历史汇总不会因关闭而立即清除。离线时待传记录最多保留7天，联网后按原使用日期补传，过期记录丢弃。

3. 账号云同步是另一个选择

不登录时可以只用本机功能。如果选择登录并启用同账号云同步，相关药品、药箱和变更数据会通过网络发送到项目的测试云，用于该账号的多手机备份与同步。这些业务数据不属于上述使用统计。云功能依赖网络和测试服务可用性，请保留重要数据的独立备份。

4. 权限只按功能需要使用

若需要本地到期通知，请按 App 提示设置通知和提醒相关权限，并检查手机的后台、电量管理限制。当前版本以手动录入为主，扫码、拍照/OCR和语音入口尚未开放。不要仅凭 App 的提醒或库存状态判断药品可以服用；请核对实际包装并咨询有资质的专业人员。

5. 本网站与下载服务

本网站是 GitHub Pages 上的静态页面，没有登录、广告、访客统计脚本，也不会连接 App 的用户数据接口。安装包来自指定的 Gitee 发行仓库。GitHub Pages 和 Gitee 提供网络服务时仍可能处理必要的网络访问日志，相关处理由各平台负责。

下载后请核对来源与版本，再由系统安装器确认。不要关闭系统安全保护或绕过风险拦截。已有 App 时建议先备份，再覆盖更新，不要先卸载旧版。

6. 反馈时，请保护自己的资料

可以到 本站 GitHub Issues反馈网页、下载或兼容性问题。Issues是公开页面，请不要上传账号资料、密码、验证码、药品清单、未脱敏截图或备份文件。没有GitHub账号也不影响本站下载和App本机使用。
